# Architecture Decision Records

Decision records capture consequential v2 choices and their tradeoffs. They cannot justify choices through legacy compatibility.

Statuses: `proposed`, `accepted`, `superseded`, or `rejected`.

Each record includes context, decision, consequences, and verification. Superseding records link both directions; accepted records are not edited to hide changed assumptions.
